# HUST 2025 级计算机类课程资料

整理华中科技大学（HUST）2025 级计算机类学习过程中的课程资料，包含课件、复习资料、试卷与答案、实验报告和课程项目，方便平时查阅、期末复习与资料归档。

## 学期与目录说明

课程文件夹采用 `学期代码-课程名称` 的命名方式。

| 学期代码 | 对应学期 | 目录示例 |
| --- | --- | --- |
| `IA` | 大一上学期 | `IA-C语言程序设计` |
| `IB` | 大一下学期 | `IB-数据结构` |

每门课程的资料放在对应文件夹内，课件、期末复习、实验程序等内容按已有子目录组织。点击下方课程名称即可进入。

## 查找与下载

### 查找资料

- 从上方课程导航进入对应课程文件夹。
- 在仓库页面按 `T`，输入课程名或文件名，可以快速定位文件。
- 查找复习资料时，可以搜索“复习”“试卷”“样卷”等关键词。

### 下载单个文件

打开文件页面，点击 **Download raw file** 下载原文件。Word、PowerPoint 和压缩包等资料可以下载到本地查看，ZIP / RAR 模板需解压后使用。

### 下载整个仓库

在仓库首页点击 **Code → Download ZIP**，下载并解压即可。

也可以使用 Git 克隆到本地，后续在仓库目录中运行 `git pull` 获取更新。

```bash
git clone https://github.com/Ekuqiw/course-material.git
```

## 查看更改记录

课程资料的新增、修改和删除都会记录在提交历史中，可以查看每次提交涉及的文件与具体变化。[查看全部提交记录](https://github.com/Ekuqiw/course-material/commits/main/)

在单个文件页面点击 **History**，可以查看该文件的历史版本。[查看 README 的更改记录](https://github.com/Ekuqiw/course-material/commits/main/README.md)

## 资料补充与纠错
